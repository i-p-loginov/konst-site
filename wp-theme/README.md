# Тема WordPress «Константа»

Блочная тема (Full Site Editing) — тот же сайт, что и статическая версия в корне репозитория, но весь контент редактируется в админке WordPress, без правки кода и без сторонних плагинов.

## Установка

1. Заархивируйте папку `konstanta` (`zip -r konstanta.zip konstanta`) и загрузите её: «Внешний вид → Темы → Добавить → Загрузить тему».
2. Активируйте тему. При активации она сама:
   - создаёт страницы «Главная», «Услуги», «О компании», «География», «Вакансии», «Контакты», «Результаты СОУТ», «Политика обработки персональных данных» с готовым контентом;
   - назначает «Главную» главной страницей и включает адреса вида `/uslugi/`;
   - создаёт главное меню и заполняет 12 отделений для карты;
   - ставит название «Константа» и подпись «Партнёр АО «ЛОЭСК»».

   Уже существующие страницы и записи не перезаписываются. Повторить наполнение: «Внешний вид → Наполнение Константы».
3. Укажите почту для заявок: «Заявки → Настройки».

Требования: WordPress 6.6+, PHP 7.4+. Проверено на WordPress 7.1.

## Что где редактируется

| Что | Где |
|---|---|
| Тексты, картинки, кнопки, секции страниц | «Страницы» — обычный редактор блоков |
| Шапка и подвал, баннер cookie | «Внешний вид → Редактор → Паттерны → Части шаблона» |
| Меню | «Внешний вид → Редактор → Навигация» |
| Название и подпись под логотипом | «Настройки → Общие» |
| Отделения, участки, районы на карте | «Отделения» |
| Заявки с сайта и адреса для уведомлений | «Заявки», «Заявки → Настройки» |

Готовые страницы целиком доступны в библиотеке блоков: «Паттерны → Константа: страницы». Стили кнопок (жёлтая, бирюзовая, контурная, контурная светлая) выбираются в настройках кнопки.

## Блоки темы

- **Карта отделений** — интерактивная карта Ленобласти и список отделений. Данные берутся из раздела «Отделения»; в настройках блока — тексты панели и кнопка.
- **Форма заявки** — заявки сохраняются в «Заявки» и уходят письмом. Если письма не приходят, на хостинге не настроена отправка почты — подключите SMTP (например, плагином WP Mail SMTP); заявки при этом всё равно сохраняются в админке.

## Разработка

Контент страниц описан в `tools/build-patterns.cjs` и сериализуется штатным сериализатором Gutenberg, поэтому блоки гарантированно открываются в редакторе без ошибок:

```
cd wp-theme/tools
npm install
npm run build   # перезаписывает konstanta/patterns/*.php
```

Стили: `assets/css/main.css` — общий стиль со статической версии, `assets/css/blocks.css` — адаптация к разметке блоков, `assets/css/editor.css` — только для редактора.
